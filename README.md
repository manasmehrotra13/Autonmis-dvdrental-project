# DVD Rental: Market Insights and Performance Analysis

Case study from my data analyst internship at Autonmis (2025), on the public PostgreSQL "dvdrental" sample database.

**What I did:** joined the rental, payment, film, customer and store tables in SQL to look at revenue, the most-rented films and categories, customer activity and store performance, and built a dashboard on the Autonmis platform.

**Files:** the datasets (zip), the dashboard and the write-up (PDFs).
